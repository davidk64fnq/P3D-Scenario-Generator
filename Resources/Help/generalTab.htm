General Tab

The General Tab serves as the primary configuration dashboard for P3D Scenario Generator. Settings configured here establish global rules, aircraft choices, departure airfields, and time of day for all generated scenario types.

Location Filter

The purpose of the Location Filter group is to define the geographical area in which a scenario is generated. For example, you might wish to generate a scenario using the Orbx True Earth Netherlands scenery. You would set up a favourite that filters by country for the Netherlands.

Important: The active location favourite acts as a global constraint across the entire application. Whenever a scenario is generated (including Circuits and Photo Tours) or a random runway is picked, the generator will strictly restrict its search to airports and runways matching your active location filters.

When editing filter values, first select an item from the Favourites combobox, then make changes to country, state, and city using the relevant dropdowns.

Favourites combobox

The application includes a default global profile named [All Locations]. Selecting this profile ensures no geographical restrictions are applied, searching all available scenery across the entire airport database.

Click the dropdown arrow next to Favourites and select an existing favourite from the list.

To create (copy) a new favourite: select an existing favourite (or [All Locations]), type the new name into the Favourites field, and press Enter. The new favourite will be created with its country, state, and city filters initialised to the values of the previously selected item.

To rename a favourite: select an existing favourite, type the new name and press Enter, then select the old name from the list and press Delete.

To delete a favourite: select an existing favourite and press Delete. A prompt will ask you to confirm the deletion.

Note: The default [All Locations] profile is protected and cannot be deleted or renamed.

Country, State, and City comboboxes

Note: The following help is written in terms of Country, but applies equally to State and City.

Understanding "None" in filters: Selecting "None" for Country, State, or City means no restriction is applied for that specific field. For example, if State is set to "Queensland" and Country is set to "None", the generator will match every airport in Queensland regardless of how its country metadata is tagged.

To add a country to the currently selected favourite: click the Country dropdown arrow, select the desired country, and press Enter. Alternatively, typing a letter will jump to the first country in the list beginning with that letter.

To delete a country from the currently selected favourite: click the Country dropdown arrow, select the country you wish to remove, and press Delete.

To clear ALL countries from the currently selected favourite: click the Country dropdown arrow, select the "None" entry (the first item in the list), and press Enter.

Note: Filter changes are only saved once the Enter or Delete key is pressed. Simply selecting an item in the list without pressing Enter or Delete will have no effect.

Random Favourite button

Click Random within the Location Filter group to randomly select a favourite from your saved location list.

Summary display field

Hover your mouse over the text box next to the Random button to see a summary tooltip of all countries, states, and cities included in the currently selected favourite.

Example Workflow

Scenario: You decide to create a favourite for your Orbx True Earth scenery regions so you can restrict scenario generation exclusively to those areas.

  1. Select [All Locations] from the Favourites dropdown to start with a clean template.
  2. Type the new name into the Favourites combobox and press Enter (e.g., Orbx TE).
  3. Select the country "Netherlands" from the Country combobox and press Enter.
  4. Select the country "United Kingdom" from the Country combobox and press Enter.
  5. Select the states "Washington", "California", "Florida", and "Oregon" from the State combobox, one at a time, pressing Enter after each.
  6. Confirm the favourite has the correct filters by hovering over the summary field next to the Random button.

Date and Time

The Date and Time group controls the environment lighting, solar angle, and seasonal conditions generated for your flight.

Date controls

Click Random Date to pick a randomly selected date across all four seasons. Alternatively, click the date picker field to specify an exact day, month, and year.

Time controls

Click Random Time to get a randomly selected flight time, experiencing conditions across all times of day—including dawn, dusk, and night. Alternatively, click the time picker field to set a specific local departure time.

Note: Prepar3D can occasionally render unexpected environment lighting for a selected time based on geographic solar calculations (for instance, a time specified for dawn may yield night lighting depending on location and season). If this occurs, simply adjust the time field in the generator and rebuild the scenario.

Runway Selection

The Runway Selection group determines your starting airport and departure runway. Selected runways are displayed in the listbox to the right of the Random button, formatted as airport ICAO code followed by the runway identifier in parentheses (e.g., EGLL (27L)).

Note: The generator deliberately omits city and geographical location details from the runway display to preserve the element of surprise when selecting a random airfield.

Random button

Click Random to pick a random airport and runway. Selection is strictly constrained by your active Location Filter.

Surface Matching: Runway filtering automatically respects your selected aircraft's landing capability. Landplanes without floats will never generate water runways, and pure floatplanes (without wheels) will strictly match water landing sites. Amphibious aircraft with both gear types can utilize either surface.

Tip: If you want to quickly pick a random runway for a region not currently saved in your favourites, simply create a temporary favourite profile (e.g., "Custom Search") and adjust its country/state/city values as needed.

Search input field

Start typing an ICAO code, airport name, or runway designator into the Search text box to dynamically filter matching airfields.

Note: Search results strictly respect your active Location Filter and selected aircraft surface capabilities. To search across the entire global airport database without regional restrictions, select [All Locations] from the Location Filter profile dropdown.

Including Add-on Scenery Runways

By default, P3D Scenario Generator includes database entries corresponding to stock Prepar3D v5 airfields, generated using Pete and John Dowson's freeware MakeRunways utility (v5.131).

To scan and include your installed add-on scenery airfields:

  1. Download MakeRunways and use its included LorbySceneryExport utility as outlined in MakeRwys README.pdf.
  2. Generate an updated runways.xml file reflecting your simulator installation.
  3. Copy the generated runways.xml file into your application user data folder at %APPDATA%\P3D Scenario Generator\. The generator will automatically detect this custom file and prioritize it over the default stock database.

MakeRunways Tips & Technical Notes:

  • Command Execution (PowerShell Required): Always execute MakeRunways from Windows PowerShell (not Command Prompt) opened inside your main Prepar3D directory. Command Prompt misinterprets the > character as a file redirection operator.
  • Recommended Command: Run .\MakeRwys />0 /Water to generate a complete database.
    • />0 – Forces MakeRunways to include short airstrips (bypassing the default 1,500m minimum length filter).
    • /Water – Scans and includes water landing sites, seaplane bases, and water runways.
  • Scenery Activation: Ensure all add-on scenery packages are active inside Prepar3D prior to executing MakeRunways.
  • Database Maintenance: You must regenerate and copy runways.xml whenever you add or modify airport scenery in Prepar3D.
  • Airports Without Defined Runways: Stock P3D v5.4 contains 23,514 airports (56,145 total runways). Of these, 1,038 airfields contain no explicit runway data in the XML output. P3D Scenario Generator ignores these runway-less airfields because scenario generation requires valid runway coordinates. To include an omitted airfield, use Airport Design Editor (ADE) to add at least one defined runway BGL record.

Aircraft Selection

The Aircraft Selection group defines which aircraft variant (fixed-wing, rotorcraft, or glider) will be loaded into Prepar3D when the scenario starts.

Runway Compatibility: Your selected aircraft's landing configuration (wheels, floats, or amphibious) acts as a dynamic filter on the Runway Selection group, ensuring random airfield picks always match your aircraft's surface capabilities.

Add Aircraft button

Click Add Aircraft to select an aircraft variant to add to your list of favourites:

  1. Navigate to the desired aircraft or helicopter folder in your Prepar3D installation (e.g., SimObjects\Airplanes\Piper_J3Cub or SimObjects\Rotorcraft\UH-60).
  2. Open the target texture.X folder for the variant (e.g., SimObjects\Airplanes\Piper_J3Cub\Texture.1).
  3. Select the image file inside that folder (typically thumbnail.jpg) and click Open.
  4. Confirm the chosen aircraft variant by hovering over the summary display field adjacent to the Add Aircraft button.

Missing or Non-Standard Thumbnails: The file dialog defaults to displaying Image Files (*.jpg, *.png, *.bmp). If an aircraft folder lacks a standard image file or only contains DirectX textures (such as .dds files), change the file dialog filter to All Files (*.*) and select any file inside the texture.X folder.

The generator will parse the aircraft configuration from the parent folder. If no valid image matching standard thumbnail dimensions (2:1 aspect ratio) is located, a default generic thumbnail is automatically assigned.

Note: Add-on aircraft may be stored in alternate directories on your PC. Simply navigate to the appropriate texture.X folder and select any file within it.

Random Aircraft button

Click Random within the Aircraft Selection group to randomly pick one aircraft variant from your saved favourites list and set it as active.

Selected aircraft combobox

Click the dropdown arrow next to Selected Aircraft and choose an aircraft variant from the list to set it as active and automatically calculate its default circuit parameters.

To rename an aircraft variant: select the variant, type a new name directly into the text box, and press Enter.

To delete an aircraft variant: select an entry from the list and press Delete. A prompt will ask you to confirm removing the variant from your favourites list.

Aircraft summary display field

Displays a quick summary of key performance values and parameters for the currently selected aircraft variant.

Tip: Hover your mouse cursor over this text field to display an expanded pop-up tooltip containing the complete set of aircraft values.

Scenario Selection

The Scenario Selection group determines the preset scenario template used for generation and assigns the title and target folder name for the exported scenario package.

Scenario combobox

Click the dropdown arrow to select a scenario preset from the list. Unlike other dropdowns in the application, this list is selection-only and does not support inline renaming or deleting of entries.

Click Random within the Scenario Selection group to randomly choose a scenario preset from the available list.

Title text box

Type a unique name for your scenario into the Title text field. This title defines both the scenario display name inside Prepar3D's menu interface and the subfolder name where scenario files are saved on your drive.

Validation Rules & Folder Checks:

  • Valid Filename Required: The scenario title cannot be empty and must not contain illegal Windows filename characters (\, /, :, *, ?, ", <, >, or |).
  • Existing Scenario Check: Before generation, the application checks your target Prepar3D scenario path (as configured on the Settings tab). If a folder matching your proposed title already exists, validation will prevent generation. You must either enter a different scenario title or delete the existing folder (ensure Prepar3D is closed before attempting to delete folders).
  • Settings Prerequisite: A valid Scenario Base Folder must be configured on the Settings tab for scenario title path validation to succeed.

Global Actions

Located along the bottom of the application window, these buttons manage configuration session states, revert control values, and compile the final scenario files.

Reset Tab button

Click Reset Tab to reset controls on the currently active tab back to their original factory default values.

Circuit Tab Behavior: When viewing the Circuit tab, clicking Reset Tab recalculates and restores standard baseline flight circuit parameters specifically tailored for the currently selected aircraft variant.

Reload Profile button

Click Reload Profile to reload your previously saved configuration profile, restoring custom control states across application tabs from the user settings file (%APPDATA%\P3D Scenario Generator\ui_settings.json).

Circuit Tab Behavior: Circuit parameters are restored specifically for the currently active aircraft variant, keyed on its unique aircraft title. If custom parameters have not yet been saved for the selected plane, standard calculated defaults are automatically applied as a fallback.

Generate Scenario button

Click Generate Scenario to validate all form inputs across active tabs and build the scenario package.

Before exporting, the generator verifies:

  • The Scenario Title is valid and does not overwrite an existing scenario folder.
  • A valid Scenario Base Folder and P3D Installation Path are configured on the Settings tab.
  • The active Location Filter and selected aircraft surface capabilities yield at least one matching airport/runway.

Upon successful validation, all required scenario files are compiled and written directly into your Prepar3D scenario directory.
