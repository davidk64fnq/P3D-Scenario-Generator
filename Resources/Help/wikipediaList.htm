Wikipedia List Tab

The Wikipedia List Tab enables you to generate visual exploration tours based on geographic tables curated on Wikipedia (such as lists of lighthouses, castles, historic battlefields, mountain passes, UNESCO World Heritage sites, or tall structures).

Design Philosophy: Wikipedia List scenarios combine low-altitude visual navigation ("IFR – I Follow Roads") with rich historical and geographical discovery. As you navigate from one landmark to the next using terrain references and the moving map overlay, flying through each landmark's proximity boundary automatically opens an in-cockpit mobile encyclopedia browser displaying the live Wikipedia article for that exact site.

Wikipedia List Parameters

The controls within the Wikipedia List Parameters group handle scraping web data, extracting geographic coordinates, sequencing points of interest into an efficient flight path, and choosing your tour segment.

Load Wiki Page button & URL Combobox

Paste or select the full URL of a Wikipedia article containing one or more sortable data tables (e.g., https://en.wikipedia.org/wiki/List_of_lighthouses_in_England).

  • Click Load Wiki Page to fetch and parse the page. The application uses an HTML parser to identify all standard tables marked with the wikitable or sortable classes.
  • Progress Reporting: Parsing status and table read counts are reported in the status bar at the bottom of the window while the page is downloaded and analyzed.

Item Link Column

Specifies the 1-based column number in the target Wikipedia table that contains the hyperlink and title of each item (default: 1).

  • In most Wikipedia list tables, the subject name and link reside in the first column (1) or second column (2).
  • Must be a positive integer greater than zero.

Coordinate Source Combobox

Determines where the generator extracts latitude and longitude coordinates for each entry:

  • Item Page: The generator queries each landmark's individual Wikipedia article link and extracts coordinates from the standard geographic coordinate tags located in the top-right corner of the page. This is the recommended option for tables that do not list explicit coordinates in their main rows.
  • Table Column: The generator searches directly within the table row for embedded latitude and longitude span tags. If coordinates cannot be located within the row, the parser automatically falls back to scraping the destination item page.

Table Names Combobox

Once a page is loaded, this dropdown is populated with summary descriptors of every detected table on the page, showing the first item, last item, and total row count (e.g., Lizard Lighthouse ... St Bees Lighthouse (48 items)). Selecting a table triggers the route sequencing algorithm.

Visit Sequence Combobox

Displays an automatically sequenced flight path that connects all items in the selected table using a nearest-neighbor distance algorithm. Each leg displays the start item number, end item number, and inter-leg distance in miles (e.g., [0] Lizard Point ... [1] St Anthony Head (14 miles)).

Start Item & Finish Item Comboboxes

Allows you to define a specific subset of the overall table route to fly rather than flying the entire list:

  • Start Item: Select the first Wikipedia landmark you wish to visit.
  • Finish Item: Select the final landmark of your tour.
  • Automatic Reordering: If you select a Start Item that appears after the Finish Item in the sequence, the application automatically swaps them to maintain a logical forward flight path.
  • Single-Item Tours: Setting the Start Item and Finish Item to the same landmark creates a single-visit tour: Departure Airfield → Landmark → Arrival Airfield.

Distance Display Field

Displays the cumulative flight distance (in miles) along the planned route between your chosen Start Item and Finish Item.

Wiki URL Window Location

Configures the display monitor, window position, screen margins, and vertical dimensions of the in-game Wikipedia article viewer panel.

Note: For a detailed explanation of multi-monitor indexing, window alignment anchors, and pixel margin offsets, see the Settings Tab: Map Window Settings documentation.

Monitor Number text box

Specifies the zero-based display index (e.g., 0, 1, 2) where the Wikipedia viewer overlay will appear.

Offset text box

Defines the pixel margin padding between the edge of the monitor and the Wikipedia panel frame.

Alignment combobox

Sets the screen anchor position (e.g., Top Right, Top Left, Bottom Right, Bottom Left, or Centered).

Monitor Width & Monitor Height text boxes

Enter the pixel resolution of your target display monitor (e.g., 1920 × 1080) to compute boundary offsets.

Window Width & Window Height

  • Window Width (Fixed): Displayed as a fixed width (500 pixels). The internal mobile container renders at a standardized 480px viewport width, perfectly matching mobile reading dimensions.
  • Window Height: Defines the vertical height of the panel in pixels (e.g., 1024). Must stay within safe monitor height bounds minus screen offsets.

How Wikipedia Tours Are Built

When compiling the scenario, the application links your selected landmarks to the nearest physical airfields and generates in-flight tracking assets:

  1. Airport Selection:
    • Departure Airfield: The generator queries the airport database to find the nearest valid runway to your chosen Start Item.
    • Destination Airfield: The generator queries the database for the nearest valid runway to your chosen Finish Item.
    • Note: Start and destination runways automatically match the landing gear capabilities (land vs. water) of your active aircraft variant.
  2. Route & Chart Generation: The complete flight path (Departure Airfield → Landmarks → Destination Airfield) is compiled. OpenStreetMap (OSM) map tiles are downloaded and stitched together to produce an overview briefing chart and progressive multi-zoom leg route images.
  3. Trigger Placement: A cylindrical proximity trigger (radius: 300 meters, vertical ceiling: 18,520 meters / ~60,000 ft) is centered directly over each landmark coordinate.
  4. Mobile Article Optimization: The scenario script automatically converts desktop Wikipedia URLs into optimized mobile endpoints (https://en.m.wikipedia.org/...useformat=mobile). This ensures articles format cleanly in single-column layout inside the Prepar3D HTML overlay panel without horizontal scrolling.

In-Flight Operations & Procedures

The scenario places your aircraft at the departure runway threshold with the simulation paused.

Pre-Flight & Departure

  1. Unpause: Unpausing the simulation triggers spoken text-to-speech mission audio reviewing your route, distance, and flight objectives.
  2. Moving Map: The in-game moving map overlay opens automatically on Leg 1, showing your aircraft and a route line connecting your departure runway to the first Wikipedia landmark.

En Route Navigation & Triggering Landmarks

  • Visual Navigation: Follow prominent roads, rivers, coastlines, and your moving map display toward the landmark coordinate.
  • Reaching the Landmark: When your aircraft enters the 300-meter cylinder trigger above the landmark:
    • The Wikipedia Viewer panel opens (or updates if already open), instantly loading the mobile Wikipedia article for that landmark.
    • The scenario variable (currentLegNo) increments automatically.
    • The in-flight Moving Map updates to show the route line connecting to the next landmark.
  • Reading in Flight: Review the history, architecture, or geographic facts of the site as you circle or fly overhead.

Arrival & Mission Completion

After passing the final Wikipedia landmark, the moving map guides you on the final leg toward your destination airfield. Land on any active runway and come to a complete stop within the 2 km airfield boundary zone to achieve goal resolution (Goal01) and close all active panels.

Global Actions

The bottom buttons (Reset Tab, Reload Profile, and Generate Scenario) are persistent window controls (see General Tab: Global Actions):

  • Reset Tab: Resets the tab fields and clears any active Wikipedia page data.
  • Reload Profile: Reloads saved window positioning parameters and cached settings from ui_settings.json.
  • Generate Scenario: Validates the tour selection, finds matching departure and destination airfields, downloads OpenStreetMap route tiles, compiles scenario XML/HTML assets, and exports the flight package to Prepar3D.
