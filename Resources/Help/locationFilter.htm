Location filter

The purpose of the Location Filter group is to define the geographical area in which a scenario is generated. For example, you might wish to generate a scenario using the Orbx True Earth Netherlands scenery. You would set up a favourite that filters by country for the Netherlands.

Important: The active location favourite acts as a global constraint across the entire application. Whenever a scenario is generated (including Circuits and Photo Tours) or a random runway is picked, the generator will strictly restrict its search to airports and runways matching your active location filters.

When editing filter values, first select an item from the Favourites combobox, then make changes to country, state, and city using the relevant dropdowns.

Favourites combobox

The application includes a default global profile named [All Locations]. Selecting this profile ensures no geographical restrictions are applied, searching all available scenery across the entire airport database.

Click the dropdown arrow next to Favourites and select an existing favourite from the list.

To create (copy) a new favourite: select an existing favourite (or [All Locations]), type the new name into the Favourites field, and press Enter. The new favourite will be created with its country, state, and city filters initialised to the values of the previously selected item.

To rename a favourite: select an existing favourite, type the new name and press Enter, then select the old name from the list and press Delete.

To delete a favourite: select an existing favourite and press Delete. A prompt will ask you to confirm the deletion.

Note: The default [All Locations] profile is protected and cannot be deleted or renamed.

Country, State, and City comboboxes

Note: The following help is written in terms of Country, but applies equally to State and City.

Understanding "None" in filters: Selecting "None" for Country, State, or City means no restriction is applied for that specific field. For example, if State is set to "Queensland" and Country is set to "None", the generator will match every airport in Queensland regardless of how its country metadata is tagged.

To add a country to the currently selected favourite: click the Country dropdown arrow, select the desired country, and press Enter. Alternatively, typing a letter will jump to the first country in the list beginning with that letter.

To delete a country from the currently selected favourite: click the Country dropdown arrow, select the country you wish to remove, and press Delete.

To clear ALL countries from the currently selected favourite: click the Country dropdown arrow, select the "None" entry (the first item in the list), and press Enter.

Note: Filter changes are only saved once the Enter or Delete key is pressed. Simply selecting an item in the list without pressing Enter or Delete will have no effect.

Random Favourite button

Click Random Favourite to randomly select a favourite from your saved list.

Summary display field

Hover your mouse over the text box next to the Random Favourite button to see a summary tooltip of all countries, states, and cities included in the currently selected favourite.

Example

Scenario: You decide to create a favourite for your Orbx True Earth scenery regions so you can restrict scenario generation exclusively to those areas.

  1. Select [All Locations] from the Favourites dropdown to start with a clean template.
  2. Type the new name into the Favourites combobox and press Enter (e.g., Orbx TE).
  3. Select the country "Netherlands" from the Country combobox and press Enter.
  4. Select the country "United Kingdom" from the Country combobox and press Enter.
  5. Select the states "Washington", "California", "Florida", and "Oregon" from the State combobox, one at a time, pressing Enter after each.
  6. Confirm the favourite has the correct filters by hovering over the summary field next to the Random Favourite button.
